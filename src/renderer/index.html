记忆管理

什么是记忆？ 记忆会注入到每次对话的系统提示中，让 AI 记住你的项目信息、偏好和上下文。

自动记忆：AI 在对话中发现关键信息（技术栈、偏好等）会自动保存，标记为「自动」。
手动记忆：在下方输入框添加，或在对话中说"记住 xxx"，标记为「手动」。

AI 每次对话时会自动读取所有记忆。

MCP 服务器管理

什么是 MCP？ Model Context Protocol — 模型上下文协议。本质：cc-wrap 拉起一个外部进程（你下面填的"启动命令"），用 stdin/stdout 跟它说 JSON-RPC，把它提供的工具暴露给模型用。
📖 如何添加？三个常用示例（点击展开）
① MiniMax · 识图/语音/绘图（需要 uv，没有就 pip install uv）
名称: minimax
启动命令: uvx
参数:     minimax-mcp
环境变量: {"MINIMAX_API_KEY": "你的 key", "MINIMAX_API_HOST": "https://api.minimaxi.com"}
② 文件系统访问（官方 filesystem-server，需要 Node.js）
名称: filesystem
启动命令: npx
参数:     -y
          @modelcontextprotocol/server-filesystem
          E:\
③ 高德地图
名称: amap
启动命令: npx
参数:     -y
          @amap/amap-maps-mcp-server
环境变量: {"AMAP_MAPS_API_KEY": "你的高德 key"}
步骤：填表 → 测试连接 看到"工具数 N"再 添加服务器。
排错：测试报"command not found" → 在终端手敲一次命令验证 PATH；启动后立刻断开 → 看 npm start 的控制台 stderr；模型不调工具 → 在对话里明说"用 xxx 的 yyy 工具"。
